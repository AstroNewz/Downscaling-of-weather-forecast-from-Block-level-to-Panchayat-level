## 2. Silent Mock Fallback Audit & Remediation

### Codebase Investigation of `MockRepository`
A forensic search of all fallback paths in `mobile/lib/` revealed:
- In `AppState`, getters `activeDownscaledWeather`, `activeAdvisories`, and `activeRisks` previously fell back to `MockRepository` constants whenever `_currentForecast == null`, including when network requests failed with an error.
- In `FarmerHomeScreen`, when `state.currentForecast == null`, the hero card rendered `MockRepository.weatherForPanchayat(...)` (displaying 28.4°C) without checking `state.hasForecastError`.
- Consequently, if the backend server was offline or unreachable, the mobile app silently presented fake synthetic data instead of informing the farmer.

### Remediation Applied
1. **AppState Safeguard Enforcement (`mobile/lib/providers/app_state.dart`):**
   ```dart
   bool get hasForecastError => _forecastError != null;

   DownscaledWeather? get activeDownscaledWeather {
     if (_currentForecast != null) {
       return AgroRepository.toDownscaledWeather(_currentForecast!);
     }
     // Strict scientific safeguard: Backend unavailable ≠ synthetic weather
     if (_forecastError != null || _backendMode != BackendMode.demo) {
       return null;
     }
     return MockRepository.mayaBazarWeather;
   }

   List<AdvisoryItem> get activeAdvisories {
     if (_currentForecast != null) {
       return AgroRepository.toAdvisoryItems(_currentForecast!);
     }
     if (_forecastError != null || _backendMode != BackendMode.demo) {
       return const [];
     }
     return MockRepository.advisories;
   }
   ```
2. **Explicit Data Unavailable Card (`mobile/lib/screens/farmer_home_screen.dart`):**
   ```dart
   if (state.hasForecastError && state.currentForecast == null) {
     return ListView(
       padding: const EdgeInsets.all(16),
       children: [
         _BackendUnavailableCard(
           error: state.forecastError ?? 'Connection to forecast service failed.',
           onRetry: () => state.refreshForecast(),
         ),
         const SizedBox(height: 20),
         _SectionHeader(label: state.tr('Select Panchayat', 'पंचायत चुनें'), icon: Icons.place_outlined),
         const SizedBox(height: 10),
         _PanchayatSelector(),
       ],
     );
   }
   ```
3. **Automated Regression Tests (`mobile/test/forensic_integration_test.dart`):**
   - Test 10: Asserts that when the backend fails, `activeDownscaledWeather` is `null` and `activeAdvisories` / `activeRisks` are empty.
   - Test 11: Asserts that when the backend fails, `FarmerHomeScreen` renders the `DATA UNAVAILABLE` banner with a `Retry Connection` button, and never renders synthetic temperatures.
